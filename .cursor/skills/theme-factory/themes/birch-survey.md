# Birch Survey

Custom Atlas theme. Not a preset. Black ink on white paper, moved by wind.

## Color Palette

- **Paper**: `#FFFFFF` — ocean, page, default ground
- **Ink**: `#0A0A0A` — bark scars, type, rules, land contours
- **Ink 90**: `color-mix(in oklab, #0A0A0A 90%, #FFFFFF)` — type only
- **Ink 60**: `color-mix(in oklab, #0A0A0A 60%, #FFFFFF)` — type only
- **Ink 30**: `color-mix(in oklab, #0A0A0A 30%, #FFFFFF)` — type only
- **Optical grey**: Bayer / blue-noise dither. Never a grey fill.

## Typography

- **Headers / body**: Satoshi 400–700 (Fontshare)
- **Map legend / coords / indices**: Geist Mono 400, 0.08em tracking, uppercase, `--text-micro`

## Best Used For

The Isak Forsberg Atlas. Ordnance-survey portfolios. Printed monochrome interfaces.

## Polarities

- Default: ink on paper
- Terminator / code: paper on ink, inverted 2px focus ring
