# Paper Studio

A quiet white studio theme for a personal developer portfolio. Paper, ink, and one cool metal line — no neon, no cream.

## Color Palette

- **Paper**: `#F6F7F9` — page canvas
- **White**: `#FFFFFF` — cards and nav
- **Ink**: `#12141A` — headlines and primary buttons
- **Mute**: `#5A6270` — body copy
- **Line**: `#E2E5EB` — hairlines
- **Steel**: `#6B7C93` — 3D edges and small labels only

## Typography

- **Headers**: Syne (geometric, architectural)
- **Body**: Figtree (clear, human)

## Best Used For

Personal portfolios, studio sites, architecture-adjacent product pages, white-space-first marketing.
